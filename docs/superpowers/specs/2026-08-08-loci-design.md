# Loci — 사진으로 기억하는 장소 기록 앱

## 배경

마음에 드는 가게를 사진으로 기록해두지만, 사진이 쌓이면 카메라 롤에 묻혀서 나중에 찾기 어렵다. 사진을 찍는 순간 위치·가게 이름·간단한 메모를 함께 붙여서, 나중에 날짜나 위치로 정리해서 다시 찾아볼 수 있게 한다.

## 범위 (v1)

- 개인용 단일 사용자 앱. 공유/협업 기능 없음.
- 크로스플랫폼 네이티브 모바일 앱(Android + iOS).
- 로컬 우선 저장 + 클라우드 백업(로그인 기반 계정 동기화).

## 기술 스택

- **앱**: Expo (React Native) + TypeScript, Expo Router로 화면 전환.
- **카메라/사진**: `expo-image-picker` (촬영 또는 갤러리에서 여러 장 선택).
- **위치**: `expo-location` (GPS 좌표 획득 → `reverseGeocodeAsync`로 주소 자동 변환).
- **로컬 저장소**: `expo-sqlite` — 장소/사진 메타데이터의 로컬 캐시. 사진 파일 자체는 기기 파일시스템(`expo-file-system`)에 저장.
- **백엔드**: Supabase.
  - Auth: 이메일/비밀번호 로그인.
  - Postgres: 장소 레코드.
  - Storage: 사진 파일.

이 조합을 고른 이유: 현재 PC에 Node.js는 있지만 Java/Flutter/Android SDK가 없어서, 네이티브 빌드 도구 없이 Expo Go로 실기기 테스트가 바로 가능한 Expo가 가장 적합함. Supabase는 이미 이 환경에 연동되어 있어 별도 백엔드 구축 없이 재사용.

## 데이터 모델

**places** (Supabase Postgres, 로컬 SQLite에 동일 스키마로 캐시)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid | PK |
| user_id | uuid | 소유자 (Supabase Auth user) |
| name | text | 가게 이름 |
| address | text | 역지오코딩된 주소 (수정 가능) |
| latitude | float | GPS 좌표 |
| longitude | float | GPS 좌표 |
| memo | text | 간단한 메모 |
| created_at | timestamptz | 기록 날짜 (정렬/필터 기준) |
| updated_at | timestamptz | |
| synced | boolean | 로컬 전용 플래그, 클라우드 업로드 완료 여부 (SQLite에만 존재) |

**photos**

| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid | PK |
| place_id | uuid | FK → places |
| storage_path | text | Supabase Storage 경로 (업로드 전엔 null) |
| local_uri | text | 기기 로컬 파일 경로 |
| sort_order | int | 표시 순서 |
| synced | boolean | 로컬 전용 |

## 화면

1. **촬영·기록 화면** (기본 진입점)
   사진 촬영/갤러리 선택(여러 장) → GPS로 주소 자동 입력(직접 수정 가능) → 가게 이름·메모 입력 → 저장.
2. **리스트 화면**
   카드형 목록(사진 썸네일 + 이름 + 주소 + 날짜). 최근순/이름순 정렬, 날짜 범위·키워드(이름/주소) 필터.
3. **상세 화면**
   장소의 사진들을 스와이프로 보기, 이름/주소/메모 수정, 삭제.
4. **로그인 화면**
   이메일/비밀번호 로그인·회원가입·로그아웃.

## 비주얼 디자인

5명의 디자이너 페르소나(각기 다른 예술적 스타일)가 독립적으로 시안을 제안하고, 서로의 안을 비평한 뒤, 한 명의 아트 디렉터가 그 피드백을 종합해 확정한 결과. 전체 과정과 5개 원안은 [Design Council 아티팩트](https://claude.ai/code/artifact/3c41a029-1aa0-4ce5-a000-0c46e98f0a05)에 기록되어 있다.

**최종 스타일**: 여백 기록부 (Margin Ledger) — 따뜻한 종이 톤 배경 위에 절제된 세리프 제목과 모노스페이스 기록 텍스트를 조합한 조용한 저널 톤. 손글씨/커시브 폰트는 전면 배제, 기록성 텍스트(주소·날짜·메모·좌표)는 예외 없이 모노스페이스로 통일.

**색상 팔레트**

| 이름 | HEX | 용도 |
|---|---|---|
| Paper (배경) | `#F5EFE2` | 전체 배경, 카드 바탕 |
| Ink (본문) | `#221F1B` | 제목, 본문, 아이콘, 저장 버튼 |
| Stamp Red (포인트) | `#A8443B` | 저장·즐겨찾기·삭제 확인 등 애정/강조 액션 |
| Antique Gold (룰선) | `#C6A15B` | 섹션 구분 얇은 룰선, 날짜 스탬프 |
| Sage-Olive (보조) | `#7E8566` | 태그 칩 테두리, GPS/위치 아이콘 |
| Mist (헤어라인) | `#DED5C2` | 리스트 구분선, 비활성 입력 밑줄 |
| Wine (희소 강조) | `#5C2430` | 선택된 태그 배경 등 극히 드문 포인트 전용 |

**타이포그래피**
- 제목(가게명·화면 타이틀): Georgia / 'Noto Serif KR' / ui-serif — 굵기 400~500, 메모에는 동일 세리프의 이탤릭.
- UI 텍스트(버튼·라벨·탭): -apple-system / 'Apple SD Gothic Neo' / 'Pretendard' / system-ui.
- 기록성 텍스트(주소·날짜·메모·좌표): 'Courier New' / Consolas / ui-monospace — 다섯 안 중 넷이 독립적으로 수렴한 표준.

**컴포넌트 규칙**
- 버튼: Ink 또는 Stamp Red 단색 채움, 라운드 4~6px(완전한 pill 금지), -0.6도 미세 회전으로 도장 모티프의 흔적만 남김.
- 카드/사진 프레임: 1px Mist 헤어라인. 사진은 좌하단 모서리에만 비대칭 라운드, 우하단에 모노스페이스+Gold 날짜 스탬프.
- 아이콘: 라인 아이콘 기본, 위치/GPS는 Sage-Olive, 저장·좋아요만 Stamp Red — 한 화면에 채도 높은 색은 동시에 하나만.
- 태그: 채움 없이 1px Sage-Olive 아웃라인, 색은 카테고리 전체에서 통일(다색 남발 금지).
- 리스트는 날짜(월 단위)로 그룹핑, 그룹 헤더는 굵은 테두리 대신 얇은 Gold 룰선 하나로 구분.

이 규칙은 구현 단계에서 Expo 앱의 테마 토큰(색상/폰트/spacing)으로 그대로 옮긴다.

## 동기화 전략

- 저장은 항상 로컬(SQLite + 파일시스템)에 먼저 커밋 — 오프라인에서도 촬영·기록이 즉시 성공.
- 저장 직후 Supabase 업로드를 시도(레코드 insert + 사진 Storage 업로드). 실패 시 `synced=false`로 남기고, 네트워크 재연결 시(NetInfo 리스너) 미동기화 항목을 재시도.
- 로그인 시: 클라우드에 있고 로컬에 없는 장소 레코드를 다운로드해서 로컬 캐시에 반영.
- 충돌 해결은 다루지 않음(단일 사용자가 한 번에 한 기기에서 쓰는 것을 전제로 v1 범위를 좁힘). 필요해지면 나중에 `updated_at` 기준 last-write-wins 추가.

## 권한 처리

- 카메라/사진첩 권한 거부: 안내 문구 표시, 이후 수동으로 사진 없이 저장은 막지 않되(사진 0장 허용) 갤러리 재시도 유도.
- 위치 권한 거부: 주소 입력란을 자동입력 없이 수동 입력으로 전환. 앱 사용 자체는 막지 않음.

## 테스트

- 자동화된 e2e 테스트는 두지 않음 (개인용 앱, RN e2e 프레임워크 구축 비용 대비 실익 낮음).
- 대신 Expo Go로 실기기에서 골든 패스(촬영→저장→리스트 확인→상세→수정/삭제, 오프라인 저장 후 재연결 시 동기화)를 수동 검증하는 것을 완료 기준으로 삼는다.
- 동기화 로직(로컬 우선 저장, 재시도 큐)처럼 분기가 있는 핵심 로직은 최소 단위 테스트(SQLite 큐 상태 전이)를 남긴다.
