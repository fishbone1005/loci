# Loci v1.1 — 카테고리, 촬영 액션시트, 안드로이드 배포

## 배경

v1(사진 기록·오프라인 우선 저장·클라우드 백업)이 실기기에서 정상 동작 확인됨. 다음 단계로 세 가지를 추가한다: 장소를 자유롭게 분류할 수 있는 카테고리 기능, 표준적인 "촬영/앨범 선택" 액션시트, 안드로이드 APK 무료 배포. iOS 정식 배포(Apple Developer $99/년)는 사용자가 나중에 별도로 진행하기로 결정 — 이번 범위에서 제외.

## 범위

- 카테고리(다대다 태그), 즉석 생성, "분류" 탭(앨범 그리드)
- 촬영 화면의 사진 추가를 액션시트(촬영하기/앨범에서 선택/취소) 방식으로 교체
- EAS Build로 안드로이드 APK 생성 + Vercel에 다운로드 페이지 배포
- iOS 정식 배포는 범위 밖 (추후 별도 작업)

## 카테고리 기능

### 데이터 모델

**categories** (로컬 SQLite + Supabase 양쪽)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid | PK |
| user_id | uuid \| null | 소유자. 로그아웃 중 생성 시 null → 기존 `claimLocalPlaces`와 동일한 패턴으로 로그인 시 인식 |
| name | text | 카테고리 이름 (예: "카페", "혼자가기좋음") |
| created_at | timestamptz | |
| synced | boolean | 로컬 전용 플래그 |

**place_categories** (다대다 연결)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| place_id | uuid | FK → places |
| category_id | uuid | FK → categories |
| synced | boolean | 로컬 전용 플래그 |

기존 `places`/`photos` 동기화 전략(로컬 우선, `runSync()`가 미동기화 항목 업로드, `claimLocalPlaces`로 로그인 시 소유권 인식)을 `categories`/`place_categories`에도 동일하게 확장한다.

### 카테고리 생성/할당

별도 "카테고리 관리" 화면은 만들지 않는다. 촬영·기록 화면과 상세 화면(수정 모드)의 태그 입력란에서:
- 기존 카테고리 목록 중 선택
- 입력한 이름이 기존에 없으면 저장 시 즉석으로 새 카테고리 생성

### 분류 탭 (새 화면)

탭바에 세 번째 탭 "분류" 추가. 그리드로 카테고리 "폴더" 타일을 보여준다: 카테고리 이름, 소속 장소 개수, 대표 사진(가장 최근에 태그된 장소의 첫 사진). 타일을 탭하면 기존 리스트 화면을 그 카테고리로 필터링한 상태로 진입한다(리스트 화면의 기존 정렬/검색/월별 필터와 동일한 UI 재사용, 카테고리 필터가 하나 추가되는 구조).

### 시각 디자인

기존 "여백 기록부" 토큰(색상/타이포)을 그대로 사용. 분류 탭의 폴더 타일은 리스트 화면의 카드 스타일과 통일감 있게 — Paper 배경, Mist 헤어라인, Gold 룰선으로 개수 표시.

## 촬영 액션시트

촬영·기록 화면의 사진 영역을 탭하면 `Alert.alert`로 "촬영하기" / "앨범에서 선택" / "취소" 3개 옵션을 띄운다(업로드/공유 시 흔히 쓰이는 표준 패턴 — 이메일·메모 앱 등에서 널리 쓰임). "촬영하기"는 `expo-image-picker`의 `launchCameraAsync()`로 카메라를 직접 실행하고, 네이티브 확인 단계("이 사진을 사용하시겠습니까?")를 거쳐 앱으로 복귀한다. 기존 "앨범에서 선택"(`launchImageLibraryAsync`, 다중 선택)은 그대로 유지. 카메라 권한(`Camera`)이 아직 `app.json`의 `expo-image-picker` 플러그인 설정에 없으므로 `cameraPermission` 문구를 추가해야 한다(이미 v1에서 `photosPermission`은 추가되어 있음 — 확인 필요).

## 안드로이드 배포

- EAS Build로 `--platform android --profile preview` (APK, AAB 아님 — 사이드로딩용) 빌드. Expo 계정 필요(무료 가입).
- 빌드된 APK를 다운로드 페이지(Vercel, 정적 HTML)에 올려서 공개 링크로 배포. 페이지에는 "설치 방법"(출처를 알 수 없는 앱 설치 허용) 안내 포함.
- 서명 키는 EAS가 관리(자동 생성/보관) — 별도 키스토어 직접 관리 불필요.

## 테스트

- 카테고리 쿼리 빌더(다대다 조인 필터)는 순수 로직 부분만 Jest 단위 테스트 대상(기존 `buildListQuery` 패턴 확장). 실제 SQLite CRUD는 기존 정책대로 자동화 테스트 대상 아님, 실기기 수동 검증.
- 촬영 액션시트는 네이티브 카메라 UI라 자동화 테스트 대상 아님, 실기기 수동 검증.
